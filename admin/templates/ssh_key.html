Autorizar num container de jogo

A partir do host Proxmox, trocando <CTID> pelo id do container:

pct exec <CTID> -- bash -lc '
  apt-get update -qq && apt-get install -y -qq openssh-server
  systemctl enable --now ssh
  mkdir -p /root/.ssh && chmod 700 /root/.ssh
  echo "{{ pubkey }}" >> /root/.ssh/authorized_keys
  chmod 600 /root/.ssh/authorized_keys
'

Containers provisionados pelo deploy-game.ps1 com PANEL_PUBKEY no .env ja saem prontos — este passo e so para os criados antes disso.

Host keys

Na primeira conexao o painel aprende e fixa a host key do container (accept-new). Se o container for recriado, a chave muda e a conexao passa a falhar com REMOTE HOST IDENTIFICATION HAS CHANGED — nesse caso remova a entrada antiga: 

ssh-keygen -f /var/lib/gamepanel/known_hosts -R <ip-do-container>

Rode dentro do container do painel, como o usuario gamepanel.
